# 用坐标逆向求行进距离

    断线重连，可以是恢复是因为我每隔10帧保存一次快照，读取快照中的信息来恢复闪断前的状态。而在快照中没有直接保存Dist（行进距离）的原因是，“绕远路就是近路”（当时没想到）。

    总之我们还是先取得敌人的路径点并计算两点间的直线距离

```Go
a, b := enemyPath[i-1], enemyPath[i]
dx, dy := b.X-a.X, b.Y-a.Y
seg := math.Hypot(dx, dy)
```

    如果seg大于零（a，b间有距离）则算出敌人坐标p.x和p.y在a，b间的什么地方。利用t作为坐标位于a，b间的几分之几处。最后算出具体行进距离。

```Go
t = ((p.X-a.X)*dx + (p.Y-a.Y)*dy) / (seg * seg)
t = math.Max(0, math.Min(1, t))

qx, qy := a.X+t*dx, a.Y+t*dy
if d := math.Hypot(p.X-qx, p.Y-qy); d < bestD {
	bestD = d
	best = acc + t*seg
}
```

func enter(c *client, roomID uint32) (*api.EnterRoomResp, error) {
	body, err := proto.Marshal(&api.EnterRoomReq{LevelId: 1, RoomId: roomID})

    读到 2004（状态）或 2005（结算）为止，二者互斥返回

```go
func nextBattle(c *client, deadline time.Time) (*api.BattleStatePush, *api.BattleSettlePush, error) {
	for time.Now().Before(deadline) {
		p, err := c.next(time.Second)
		if err != nil {
			return nil, nil, err
		}
		if p == nil {
			continue
		}
		switch p.MessageID {
		case msgState:
			var s api.BattleStatePush
			if err := proto.Unmarshal(p.Payload, &s); err != nil {
				return nil, nil, err
			}
			return &s, nil, nil
		case msgSettle:
			var s api.BattleSettlePush
			if err := proto.Unmarshal(p.Payload, &s); err != nil {
				return nil, nil, err
			}
			return nil, &s, nil
		}
	}
	return nil, nil, fmt.Errorf("等待战斗推送超时")
}
```
