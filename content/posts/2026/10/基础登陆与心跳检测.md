# 登陆

    用”net“的函数，先对端口进行监听。再对监听的端口进行处理

```
listener, err := net.Listen("tcp", ":8888")
...
conn, err := listener.Accept()
...
go handleConn(conn)
```

    将收到的消息编码成包，然后写回（此时MessageID为1001）

```
pkt, _ := common.Encode(p.MessageID, p.Payload)
_, _ = loginConn.Write(pkt)
```

    login接收到包（MessageID为1001），进行登陆检测（暂时用简单方法，还没链接数据库），检测完后写回。（MessageID为1002）

```
n, err := conn.Read(readBuf)
if p.MessageID == 1001 {
				body := string(p.Payload)
				fmt.Printf("收到登录请求：%s\n", body)
				if body == "test" {
					respMsgId = 1002
					respBody = []byte("ok:session-10086")
				} else {
					respMsgId = 1002
					respBody = []byte("err:账号密码错误")
				}

				respPkt, _ := common.Encode(respMsgId, respBody)
				_, _ = conn.Write(respPkt)
			}
```

    之后经过再次的网关，写回给链接的用户。

```
for _, cli := range clientMap {
				pkt, _ := common.Encode(p.MessageID, p.Payload)
				_, _ = cli.conn.Write(pkt)
			}
```

    以此完成一次登陆操作

# 心跳检测

    我们先设定一个10秒，超过这个时间则视为断联。

```
const heartbeatTimeout = 10 * time.Second
```

    每次收到Read的数据时，通知重置心跳计时。

```
n, err := conn.Read(readBuf)
...
select {
		case recvCh <- struct{}{}:
		default:
		}
```

   用一个gocontinue来检测心跳，是否超时。

```
go func() {
		for {
			select {
			case <-ticker.C:
				fmt.Printf("连接 %v 心跳超时，断开\n", remote)
				_ = conn.Close()
				return
			case <-recvCh:
				ticker.Reset(heartbeatTimeout)
			}
		}
	}()
```
