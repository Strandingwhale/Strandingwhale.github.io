第一个新文件“packet”

前言 晚上好pithub pages 和博客园的读者们，我开始建造我的游戏，暂且叫他无底深城吧。首先是构建后端，我打算用go语言来做。我之前学过一点，但不多，也算从头再来。 第一个文件 “packet.go”是将消息 ID + protobuf 二进制 → 组装成 [4字节长度][2字节msgId][payload] 的包（大端）并从字节缓冲区里不断读，切出完整包，处理半包、粘包的功能文件 这些花了我几个小时， 总之收获还蛮多的。而且这和网上的课程相去甚远，像C++里的STL，别人不教，就算你精通了基础，也还是不一样。好了先到这，我睡了。

前言 早上好git pages和博客园的读者们，现在是2026年的10月20号，距离期末只剩下半个学期了，时间过去的真快。感觉还有好多事没开始，最近也是忙得要死。不过有一点庆幸的是这个学期的课程作业终于做完了，是一个日历，其实本体很简单，只是学习怎么用MySQL花了的时间。之后总算有时间去构造我的超级项目了。 这个项目肯定会是一个超级好玩，而且让我简历超级加分的东西。虽然我还不知道要写点什么。那就一点一点挤出来把。 前言先到这了，我还是第一次写博客，也不知道要说什么，但事情总会变好的，像《献给阿尔及农的花束》的主角一样，越写越好，不过我可没打算做前额叶手术。 项目计划 好的项目计划是这样，我要做一个分布式塔防游戏项目，因为我喜欢玩明日方舟和kr。 目标：单机塔防对局，服务器计算，分布式多服务拆分；客户端仅做表层，只转发指令、渲染画面，不参与伤害/AI判定。 技术栈：Go、TCP、Protobuf、Linux、MySQL、Redis、Docker Compose、Prometheus+Grafana、wrk压测 配套：极简Unity客户端 明确不做 为了控制工作量 防止无限膨胀：充值、支付；社交、好友、工会、跨服匹配；复杂动画、高质量美术资源；跨服务器排行榜；反作弊系统。
